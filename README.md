## Full-stack  - React.ts + Laravel + MySQL
Проект для соревнований , библеотека книг

## Инструкция

Сначала при клонирование проекта нужно открыть терминал и разделить его на два окна и написать в первом окне

```bash
$ cd client
```

И во втроем окне

```bash
$ cd server
```

Затем в обоих окнах нужно установить зависимости

## Установка зависимостей

Для client
```bash
$ npm install
```

Для server
```bash
$ composer install
```

## Запуск проекта

Для клиента 
```bash
$ npm run dev
```

Для сервера
```bash
$ php artisan serve
```

## Примичание для серверной части

Перед запуском сервера необходимо прописать 
```bash
$ php artisan migrate
```
для миграций и после прописать

```bash
$ php artisan db:seed DatabaseSeeder
```
для заполнения тестовыми данными

Также необоходимо будет локально установить poppler и tesseract-ocr  
Это две утилиты для преобразования PDF файла в текст и перевод текста
